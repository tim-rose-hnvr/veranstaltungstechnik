# Entwurf

Die Arbeitsdateien der Entwurfsfläche: acht Blätter, aus denen die
Entwurfsseite zusammengesetzt wird.

| Datei | Blatt |
|---|---|
| `Main.dc.html` | Sprechstelle, Sicht eines Delegierten |
| `Leitung.dc.html` | Sprechstelle, Sicht der Sitzungsleitung |
| `Abstimmung.dc.html` | laufende Abstimmung, Vollbild |
| `Namensschild.dc.html` | Namensschild in drei Zuständen |
| `Dolmetscher.dc.html` | Dolmetscherplatz |
| `Webseite-Start.dc.html` | Webseite, Startseite |
| `Webseite-System.dc.html` | Webseite, Seite „System" |
| `Bausteine.dc.html` | Farben, Schrift, Zustände, Maße |
| `canvas.json` | Anordnung, Seiten und Notizen der Fläche |

Es sind **Entwürfe zum Ansehen**, keine bedienbaren Prototypen. Was hier
beschlossen wird, wandert von Hand nach `web/` und `webseite/` — die
gebaute Oberfläche bleibt die Wahrheit.

Die zusammengesetzte Seite (`conferencecue-entwurf.html`) steht nicht im
Repository: sie ist Erzeugnis, nicht Quelle, und bringt den Editor als
Ballast mit.

## Farben, die hier festgehalten sind

Alle Werte stammen aus `webseite/stil.css` und `web/index.html`. Eine
Abweichung ist ausdrücklich vermerkt und noch nicht entschieden: das
offene Mikrofon ist auf der Webseite und am Namensschild `#c8102e`, in
der Sprechstelle `#dc2626`. Vorschlag auf dem Blatt „Bausteine":
überall `#c8102e`.
